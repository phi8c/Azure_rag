Khi gọi API chat/query và chat/helpdesk
thì trong reponse có trả kèm 2 trường là drive_id và drive_item_id

khi nhấn vào source thì hãy gọi API dưới đây và truyền drive_id và drive_item_id vào

Dùng API này khi người dùng click vào một source trong câu trả lời Chat để lấy URL preview tài liệu SharePoint.

```http
POST https://ai.sadec.co/api/documents/preview
Content-Type: application/json
```

**Request body**

```json
{
  "drive_id": "b!vZ8XbWg5bEqDZ-0F1fdy...",
  "drive_item_id": "014VNYPP..."
}
```

Hai giá trị `drive_id` và `drive_item_id` lấy trực tiếp từ source mà **Chat API trả về**.

**Response thành công — `200 OK`**

```json
{
  "preview_url": "https://..."
}
```

`preview_url` là URL tạm thời do Microsoft Graph tạo ra. FE dùng URL này để render document preview bằng `iframe`:

```tsx
<iframe
  src={previewUrl}
  title="Document Preview"
  width="100%"
  height="100%"
  style={{ border: "none" }}
/>
```

Flow FE:

```text
Chat API
   ↓
source
{
  source_url,
  drive_id,
  drive_item_id
}
   ↓
User click source
   ↓
POST /documents/preview
{
  drive_id,
  drive_item_id
}
   ↓
{
  preview_url
}
   ↓
iframe src={preview_url}
```

Ví dụ React đầy đủ phần gọi API:

```tsx
const openDocumentPreview = async (
  driveId: string,
  driveItemId: string
) => {
  const response = await fetch("/documents/preview", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      drive_id: driveId,
      drive_item_id: driveItemId,
    }),
  });

  if (!response.ok) {
    throw new Error("Failed to load document preview");
  }

  const data = await response.json();

  setPreviewUrl(data.preview_url);
};
```

Sau đó:

```tsx
{previewUrl && (
  <iframe
    src={previewUrl}
    title="Document Preview"
    className="w-full h-full border-0"
  />
)}
```

**Lưu ý cho FE:** không cache/lưu lâu dài `preview_url`. Khi user cần mở preview thì gọi `/documents/preview` để lấy URL mới. `source_url` hiện tại vẫn có thể giữ lại để hỗ trợ chức năng **Open in SharePoint**.

Vậy FE chỉ cần hiểu đúng một câu: **click source → lấy `drive_id` + `drive_item_id` từ source → gọi `/documents/preview` → lấy `preview_url` → nhét vào iframe.**
